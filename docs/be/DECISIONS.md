# BE·Infra 추가 결정 기록

## 2026-10-09 참가자 간 역할 교환 금지

사용자 확정: 실제 4인 게임에서 참가자는 서로 역할을 교환할 수 없다. 최초 배정된 역할을 게임 동안 유지하고 새로고침·재접속으로 다시 배정하지 않는다.

- 이전 시나리오·계획의 30초 교환 창, 상대 동의, 팀당 1회 교환은 이번 결정으로 대체한다. PR-3에서 교환 UI나 `propose-swap`/`respond-swap`을 구현하지 않는다.
- 현재 v2 서버는 교환 액션을 지원하지 않고 `game.swap`을 `{window_ends_at:null, used:false, pending:null}`로 반환한다. 이 비활성 상태를 API 호환용으로 유지하며 교환 요청은 계속 거절한다. 기존 코스 타입의 `roleSwapEnabled`·`roleSwapSeconds` 필드가 교환을 허용한다는 의미는 아니다.
- 앞서 승인한 로컬 dev의 별도 v1 혼자 체험에서 보직을 바꾸는 기능은 시연용이다. 실제 참가자 간 교환과 구분하고 실제 4인 방에 적용하지 않는다.
- PR-3의 우선 범위는 GPS 필수 도착과 기존 출발 흐름의 미연결 부분·재접속 유지 검증이다. 역할 교환은 후속 구현 목록에서도 제외한다.

## 2026-10-09 GPS 필수 진행 정책

사용자 확정: 실제 게임은 GPS 기준으로 해당 거점에 도착해야 진행한다. 기존 정문의 전원 도착 조건과 함께 적용한다. 아래는 PR-3 구현 기준이며 이번 결정 기록만으로 현재 서버 동작이 바뀌지는 않는다.

- 입장·보직 공개·준비는 기존 흐름을 유지한다. 실제 4인 코스의 미션 진입·문제 제출·보고·자물쇠는 네 명의 GPS 도착 조건을 충족한 뒤 허용한다. 도착 전 개인 문제·단서의 응답 공개 범위도 함께 점검한다.
- QR·지휘관 수동 확인·진행자 확인으로 실제 코스의 GPS 조건을 우회하지 않는다. 이전 계획의 D2 `QR → 지휘관 수동(30초)` 대체안은 이 결정으로 대체한다. 방 합류 QR은 도착 확인과 별개이므로 유지한다.
- 앞서 승인한 로컬 dev 시연·dev 합성 코스의 모의 도착은 개발 확인용으로 분리한다. 실제 현장 도착으로 표시하거나 운영 코스에 허용하지 않는다.
- GPS 권한 거부·측위 실패·미확정 좌표이면 미션을 잠근 채 권한 설정·재측정을 안내한다. 좌표 후보를 임의로 confirmed=true로 바꾸거나 현장 반경을 지어내지 않는다.
- 현재 프롤로그의 보직 공개·역할 안내·준비·지휘관 출발은 이미 구현됐다. PR-3은 이를 재구현하지 않고 GPS 필수 진행을 우선 보완한다. P-03 확인 문구의 미연결 부분은 별도 범위로 구분하며 역할 교환은 구현하지 않는다.
- 현재 위치 판정은 클라이언트의 `judgeArrival` 후 `method:gps` 보고를 신뢰한다. 이를 서버가 실제 위치를 검증한 것으로 표현하지 않는다. 위치 데이터 전송·보관 정책을 임의로 바꾸지 않으며 현장 확인 및 API 직접 호출에 대한 보장 범위를 PR-3에서 명시한다.

현재 PR-2 v2에는 지휘관 본인의 30초 후 수동 도착이 남아 있고 QR 도착 검증은 없다. 수동 경로 차단·GPS 권한 안내 수정·설정 연결·도착 전후 API 및 네 세션 검증은 PR-3의 남은 구현이다. 이번 결정 기록은 GPS 동작 변경이나 클라우드 배포를 뜻하지 않는다.

## 2026-10-09 UI 누락 연결

- 사용자 확정: 자동 시연·보직 전환·장면 건너뛰기는 **로컬 dev의 별도 v1 혼자 체험 방**에서 사용한다. v2 개발 환경에서도 실행할 수 있게 하되 실제 4인 v2 방의 진행 조건은 유지한다.
- 숫자 획득 → 조사·해설 → 자물쇠 왕복, 사초 → 정문 결과 → 기록첩을 연결한다. 완료된 공개 사초 본문·도장과 인증된 본인 기록만 보여 준다. 답안 초안은 메모리로만 유지하고 브라우저 저장소에 추가하지 않는다.
- API 추가: `game.completion`으로 완료 방식을 재조회하고 `self.journal`로 본인 검증 결과·기록·출처·해설을 조회한다. 정답 배열·해시·숫자·전달 단서·타 역할 기록을 포함하지 않는다. 기존 dispatch/CAS/멱등성과 감점·시도 규칙은 유지한다.
- 사초 공개 보상 `char`/`body`는 선택형이며 완료 후에만 제공한다. 기존 불변 코스는 수정하지 않고, 본문 추가 시 새 리비전을 seed와 Edge의 동일한 기존 salt로 등록한다. 새 마이그레이션·비밀값은 없고 Edge·웹 재배포가 필요하다.
- 범위는 정문 UI 복원까지다. 후속 거점 이동·봉지·추모의 벽 공동 기록·전체 코스 결과·랭킹은 후속 PR로 남긴다. 역할 교환은 이후 사용자 결정으로 제외했다. [적용 안내](../fe/UI_RESTORATION.md).
