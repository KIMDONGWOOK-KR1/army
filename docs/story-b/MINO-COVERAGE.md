# MINO 시나리오 구현 대응표

2026-10-11 최신 반영. 대상: `GPS_MINO_1st_scenario_current.md`의 이야기·나레이션·미션. 사용자의 후속 지시에 따라 추모의 벽은 MINO 문항 대신 1차 결과 그대로 유지한다. 원본 대본과 실제 정답표는 커밋하지 않는다.

|---|---|---|

| P-02 | 기존 보직 배정 연출 + MINO 공통 나레이션·역할별 소개 | 보직 교환은 기존 설정대로 꺼짐. 정찰원 소개는 사진 대체 경로에 맞춤 |
| P-03 | 준비 나레이션, 보직별 준비 버튼, 네 명 준비 후 출발 | 카메라·화면 유지 권한을 새로 요구하지 않음. 기존 위치·소리 기능과 자막 사용 |
| G-00 | 오류 보고서 수신 나레이션·안내 | 학습용으로 바꾼 문장임을 명시 |
| G-01 | 진위 4문장 → 사건 카드 순서 → 판단 근거 직접 작성 | 세 동료 보고 후 입력 가능. 조형물 문장은 다른 역할의 답을 미리 공개하지 않도록 조정 |

| G-06 | 시작의 기록 사초·다음 거점 나레이션·이동 카드 | 정답 키를 사초·나레이션에 재출력하지 않음 |
| Y-00 | 용봉관 도착·자료 조사 안내 | 현장 운영 여부를 자동으로 단정하지 않음 |
| Y-01 | 외형 특징 2개 → 과거 용도 → 관찰·출처·한계 | 허가된 과거 사진이 없어 현재 모습·공식 설명 경로 |
| Y-02 | 자료 유형/기능 4개 연결 → 이유 선택 → 자료 기록 | 자료 제목·유형·시기·제공기관·알 수 있는 내용을 암호해독관에게 전달. 실물 전시를 가정하지 않음 |
| Y-03 | 출처 상황 카드 4개 연결 → OX → 전달된 자료의 한계 | 통신원 자료 수신 후 확인·누락·한계·추가 질문 기록 |
| Y-04 | 사실/거짓/근거 부족 3개 분류 → 근거 연결 → 보고서 수정 | 동료 보고 후 입력. 확인한 내용·추가 확인할 내용 두 필드 필수 |
| Y-05 | 두 번째 자물쇠·사초·나레이션 | 외부 대체 조사를 결과와 개인 기록에 표시 |
| W-00~06 | **1차 추모의 벽 그대로** | 기존 소개·묵념·국화·사초·나레이션·이동 카드. MINO 인물 문제·가치 연결·공동 추모 문장은 넣지 않음 |
| B-00 | 세 장의 사초를 회고 화면에 표시·집결 나레이션 | 세 번째 카드는 기존 헌화 사초. 봉지에서 새 사초를 지급하지 않음 |
| B-01 | 보직별 회고 질문·안내 자막·개인 기록 저장 | 화면 제출 순서는 강제하지 않음. 현장에서 정찰원→통신원→암호해독관→지휘관 순으로 대화 가능 |
| B-02 | 가치 낱말 3개·조합 문장 미리보기·이유·세 단계 도움·전원 동의 | 정답 조합 없음. 원문의 정답 예시형 3단계는 선택 방법 안내로 조정. 수정 시 동의 초기화 |
| B-03 | 완료 나레이션·최종 안내·결과·개인/공동 기록 복구 | 기존 집계 구조 유지. 추모는 헌화 완료로 표시. 새 점수·랭킹은 도입하지 않음 |

정문 13개 + 용봉관 12개 = **25개 세부 문항**. 출처·자유 기록 문항도 독립 단계로 센다. 모든 조사 문항은 서로 다른 1→3단계 힌트가 있으며, 3단계에는 답을 쓰지 않는다. 3단계 해설 경로는 독립 해결과 구분해 저장한다.

## 별도 준비·결정이 필요한 것

- 조형물 부분 사진과 용봉관 과거 사진: 원본·권리·촬영 시기·설명 확정 필요. 현재는 원문이 허용한 메모·공식 자료 경로로 완주한다.
- 인물: 새 인물 문제는 없음. 기존 추모의 벽에 표시하는 소개·인원 표현은 현장 안내와 최종 대조 필요.
- 연도·장소·현장 안내: 정문 사건과 용봉관 자료는 공식 공개 설명을 사용. 안내판의 최신 표기, 관람 가능 시간, 집결 위치·거리는 현장 확인 필요.
- 서술형 표기: 서버 비공개 파일에 등록한 동의 표현 범위만 자동 인정한다. 의미가 같은 새 표현의 추가 범위·운영 검수자 미정.
- 새 문서의 정문·용봉관 힌트 감점 0/10/10, 무힌트 보너스 0을 새 코스에 적용했다. 시간 점수·랭킹·운영자 대행·사진 제공은 미확정이다.
- 나레이션은 모두 글 자막이며 새 음성 파일을 녹음하거나 합성하지 않았다. 기존 음원과 3D 지도 유지.

최신 공통 입력 정책: 모든 일반 v2 문항에서 확인 방식·확인한 출처·연결할 자료 선택기를 제거했다. 문항 자체의 출처·기록 필드는 유지하고 수집하지 않은 방식은 null로 둔다. [UI/UX 적용 상세](UIUX-CURRENT.md).
