# 보행 동선과 전체 체험 보완

2026-10-11. MINO 구현 `a3876fb` 이후 후속 수정. 비교 기준은 1차 결과 `965239e`, 작업 브랜치는 `feat/story-b`다. GitHub 푸시·PR은 하지 않는다.

## 용봉관 뒤에 끝나던 이유와 수정

사용자 브라우저의 완료 화면은 사초가 두 장인 기존 v1 혼자 시연 방이었다. 네 사람이 시작하는 MINO 방은 이미 네 거점을 포함했지만, **혼자 데모 체험** 진입은 preset에 관계없이 예전 두 거점 코스를 만들고 있었다.

`story-b`에서는 두 진입이 모두 정문 → 용봉관 → 용봉열사 추모의 벽 → 봉지로 연결된다. 혼자 체험에만 서버가 시연 동료 세 명을 만들고, 소유자가 네 보직을 번갈아 맡을 수 있다. 보직 변경은 4인 방과 Supabase의 일반 게임 엔진에서는 허용하지 않는다. 모의 도착만 동료들과 함께 처리하며, GPS 도착을 대신 인증하지 않는다.

미션 판정·보고·해설 확인·헌화·개인 회고·공동 기록·네 보직 동의는 원래 엔진을 사용한다. 용봉관 완료 화면에는 추모의 벽 이동 카드가 나오고, 결과 화면은 봉지의 마지막 동의 후에 열린다. 보직을 바꾸면 입력 폼을 새로 열어 다른 보직의 회고 초안이 남지 않는다.

기존 추모의 벽 소개·묵념·국화 헌화와 추모 소리 규칙을 유지한다. 새 추모탑이나 역사적 장소를 만들지 않는다. 이전에 만든 v1 방의 진행 자료는 유지되며 새 체험에서 수정된 코스를 사용한다. 전체 코스 혼자 체험은 보직을 바꿔 직접 진행한다. 기존 v1 자동 시연·장면 건너뛰기 기능을 MINO의 완료 판정으로 사용하지 않는다.

## 지도에서 확인하고 고친 내용

- 가로수는 도로 중심선에서 일정 간격으로 만든 장식이었다. 이 줄이 실제 보도 경로와 겹쳤다. 장식 가로수 줄을 잔디 쪽으로 옮기고, 모든 일반 나무의 수관 반경에 캐릭터 여유 2m를 더한 구간에는 나무를 그리지 않는다. 생략한 나무의 그림자·보호틀도 남기지 않는다. 이 배치는 실제 수목 측량 결과가 아니다.
- 시연 위치는 보행 경로 위의 진행 거리로 계산한다. 계산된 위치를 다시 직선으로 따라가던 보간 때문에 모퉁이를 안쪽으로 잘랐으므로, 시연 이동에서는 경로 위 위치를 그대로 사용한다. 실제 GPS 값에는 이 보행 경로 강제를 적용하지 않는다.
- 보행 경로를 굽는 그래프에서 보도와 횡단 연결만 허용한다. 네 구간 모두 연결되며, 기존 경로 좌표와 동일하다. 연결이 없으면 직선 지름길을 만드는 대신 생성에 실패한다.
- 지도 생성기가 일반 차도만 횡단 지점으로 수집하던 문제를 수정해 교내 서비스 도로도 포함한다. OSM 노드 식별자와 도색 정보도 파생 지도에 저장한다. `crossing:markings=no` 또는 `crossing=unmarked`를 우선하고, `marked`·`uncontrolled` 등 도색 근거가 있을 때 흰 줄을 표시한다. 정보가 없으면 표시를 추정하지 않는다.
- 새 횡단 지점 주변의 장식 말뚝도 보행 여유 공간을 지킨다. 먼 말뚝 장식은 생략해 기존 삼각형 예산 검사를 유지한다. 건물·캐릭터·3D 에셋·음원은 교체하지 않았다.

## 실제 위치 대조와 한계

기존 공개 OSM 내보내기 자료를 사용해 파생 지도를 다시 만들었다. 보행 경로에서 5m 이내인 횡단 지점 다섯 곳은 **2026-10-11 현재 OpenStreetMap API 응답**과 위치 및 태그가 일치했다. 원본 좌표 파일과 API 응답 파일은 커밋하지 않는다.

| 공개 지도 지점 | 확인 결과 | 지도 표시 |
|---|---|---|
| [1211682775](https://www.openstreetmap.org/node/1211682775) | 위치 일치, `crossing=uncontrolled`, 마지막 수정 2022-12-28 | 흰 줄 |
| [10252846149](https://www.openstreetmap.org/node/10252846149) | 위치 일치, `crossing=uncontrolled`, 마지막 수정 2022-12-27 | 흰 줄 |
| [10252846150](https://www.openstreetmap.org/node/10252846150) | 위치 일치, `crossing=uncontrolled`, 마지막 수정 2022-12-27 | 흰 줄 |
| [10252846171](https://www.openstreetmap.org/node/10252846171) | 위치 일치, 도색 정보 없음, 마지막 수정 2022-12-11 | 흰 줄 미표시·현장 확인 필요 |
| [10310832393](https://www.openstreetmap.org/node/10310832393) | 위치 일치, `crossing=uncontrolled`, 마지막 수정 2023-01-06 | 흰 줄 |

태그 해석은 [OSM의 uncontrolled 정의](https://wiki.openstreetmap.org/wiki/Tag:crossing%3Duncontrolled)를 따른다. 최신 API와의 일치는 최신 현장 도색·공사·통행 안전을 확인했다는 뜻은 아니다. 학교의 [용봉관·용봉탑 안내](https://518trail.jnu.ac.kr/SubPage.aspx?PageCode=K21000)와 기존 추모의 벽 명칭을 유지했으며, 이번 수정에서 인물·연도에 관한 새 이야기를 추가하지 않았다.

실제 횡단보도의 폭·방향·도색 상태, 정보가 없는 위 지점, 수목·화단·말뚝의 실물 위치, 안전한 집결 위치와 네 휴대전화의 야외 GPS는 현장에서 확인해야 한다.

- 기존 네 사람 시험은 쿠키가 분리된 네 브라우저에서 정상 풀이와 1→3단계 해설 경로로 끝까지 진행한다. 추가 혼자 시험은 홈의 실제 진입 버튼, 네 보직 전환, 힌트·보고·해설 개방, 추모 묵념·네 송이 헌화, 네 회고·공동 동의·새로고침을 검사한다. 일반 방의 보직 전환 금지와 요청 재전송도 단위 시험한다.
