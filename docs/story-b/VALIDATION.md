## 네 사람이 끝까지 진행되는지 확인한 방법

Chrome과 Playwright WebKit 각각 쿠키가 분리된 브라우저 context 네 개를 만든다. 방 생성·합류·서버 보직 배정·준비·모의 도착은 API를 사용한다. 보직을 고정하거나 서버 진행 상태를 직접 수정하지 않는다.

정상 경로는 네 역할의 실제 UI에서 총 25개 문항을 제출한다. 주파수는 지휘관용 개인 입력과 같은 값을 서버 전용 파일에서 읽어 통신원 다이얼에 입력한다. 통신 복원→정찰원 조사·보고→통신원 낱말→나머지 보고의 선행 조건을 따른다. 정문과 용봉관의 OX·순서·연결·분류·다중 선택·텍스트·출처 메모를 모두 직접 제출하며 3단계 힌트로 건너뛰지 않는다. 보고와 자물쇠 제출은 API를 사용한다.

용봉관에서는 지휘관의 외부 대체 조사 버튼을 누르고 동일한 미션을 완료한다. 통신원 기록이 암호해독관에게 전달되고, 근거 검토 후 지휘관 문항이 열리는지 확인한다.

힌트 경로는 지휘관이 네 역할에게 1→3단계 힌트를 요청한 뒤 선행 조사·보고 순서에 맞춰 보고와 해설 읽음 확인을 처리한다. 해설 전용 개방으로 다음 거점에 도착한다.

두 경로 모두 네 UI에서 묵념 마치기·국화 올리기를 누르고, 기존 추모 소개·점수/자물쇠/카운트다운 부재·판정 소리 이벤트 부재를 확인한다. 봉지에서 개인 회고와 공동 문장·근거를 작성하고 네 명이 동의한다. 회고 수정으로 이전 동의가 무효화되는지, 결과의 사초 3/3과 최종 공동 기록이 새로고침 후 복구되는지 확인한다. 다른 역할의 비공개 회고가 보이지 않는지도 검사한다.

추가 대본 시험은 나레이션을 켠 상태에서 MINO 프롤로그 → 보직 공개 → 준비 나레이션 → 역할별 소개가 표시되는지 확인한다.

## 화면 검증

정상 풀이의 각 문항을 제출하기 전에 폭 320·360·375·390·412·430px × 글자 100%·130%를 검사한다. 사초·헌화·공동 기록·결과 화면에도 적용한다. 글자 확대는 계산된 글자 크기를 1.3배로 바꾸는 방식이다. 가로 넘침과 주요 문항/라벨/본문 잘림을 검사하며 긴 선택지는 줄바꿈 가능한 목록과 짧은 항목 번호로 표시한다.

관찰 메모 폼을 정답 입력 전에 캡처해 확인한다. 정답이나 개인 잠금 숫자를 캡처하지 않는다. 기존 제목·버튼 메이플스토리체, 본문 Noto Sans, 새 기록 카드 Noto Serif를 사용한다.

모든 화면·문장 조합의 겹침 부재를 보증하는 검사는 아니다. 실제 휴대전화의 OS 글자 확대·화면 낭독기·야외 가독성 시험은 수행하지 않았다.

## 검증 중 발견하고 처리한 문제

- 기존 `.next/types`에 번호가 붙은 중복 생성 파일이 있어 타입 검사에서 중복 선언 오류가 났다. 빌드 후 한 번 사라졌다 다시 나타나, 기존 캐시를 보존하고 `.next`를 임시 로컬 저장소의 심볼릭 링크로 분리했다. 프로젝트 타입 설정을 완화하거나 소스 검사를 제외하지 않았다. 분리 후 빌드·타입 검사를 다시 수행했다.
- 캐시 폴더를 임시 위치로 옮기는 명령이 지연되어 종료했다. 앱 소스는 이동하지 않았다. 이후 같은 폴더 안에서 이전 캐시 이름을 바꿔 보존했다. 임시 캐시 첫 빌드에서는 의존성 경로가 없어 실패했고, 임시 실행 폴더에 기존 `node_modules` 연결을 둔 후 빌드가 통과했다.
- 새 선행 조건 때문에 ‘정찰원에게만 해설→즉시 보고’ 시험이 거부됐다. 모든 관련 조사에 해설을 제공한 후 보고하도록 시험 순서를 고쳤다. 서버의 협동 조건을 제거하지 않았다.
- 로컬 포트와 브라우저 실행은 승인된 실행 환경에서 검사했다. Playwright Chromium 대신 설치된 Chrome 채널을 사용한다.
- trace와 자동 스크린샷은 끈다. 실제 판정값은 Git에서 제외된 서버 파일에서 테스트 프로세스가 읽고, 소스·콘솔에 다시 쓰지 않는다.

## 미수행·한계

실제 네 사람이 휴대전화 네 대로 걷는 시험, 현장 GPS, Supabase·Realtime 배포, 사진 권리 검수, 역사·서술형 답안의 사람 검수, 교육 효과 평가는 수행하지 않았다. 별도의 원음 나레이션은 만들지 않았다. 기존 전체 브라우저 시험 모음을 실행한 것은 아니며 새 코스 정상/해설/대본 시험을 실행했다. GitHub 푸시·PR은 하지 않았다.
