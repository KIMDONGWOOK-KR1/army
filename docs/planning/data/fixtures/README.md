# 테스트 픽스처

원시 GPS CSV는 위치 좌표가 있는 로컬 시험 자료이므로 초기 공개 문서 PR에 포함하지 않는다. 아래 파일 설명은 수집한 시험 자료의 기록이며 CSV가 원격 저장소에 있다는 뜻은 아니다. 공개 검증용 합성 자료는 `synthetic_*.csv` 이름으로 별도 관리한다.

- `night_test_iphone_20261005.csv`: 10/5 야간 사전 테스트(아이폰). CSV의 site가 '정문'이지만 **실제 정문이 아닌 임의 지점**이다. 판정 로직 교차 검증용으로만 쓰고 논문 수치로 쓰지 않는다.
  - 시행 1 정지(24초, 24개 중 17개가 오차 40m 초과로 버려짐), 시행 2 진입(표시선 버튼이 5번 눌림 — 수정 전 버전).
  - `python3 analyze_gps.py` 결과: 반경 30m에서 진입 성공, 필터 후 정지 오차 4.6m.
- 10/6 답사 CSV를 받으면 여기에 추가한다.
