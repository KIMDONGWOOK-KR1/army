# UI·서체·표정 보정 (2026-10-15)

## 요청과 판단
첨부된 기록 화면의 어색한 줄바꿈과 잘린 버튼을 고치고, 주요 플레이 화면을 작은 폰에서도 사용할 수 있게 한다. 기존 C02 사람 캐릭터와 네 보직 소품을 유지하면서 표정에 작은 차이를 준다.

## 반영
- 기록 본문과 하단 조작을 분리했다. 본문만 스크롤하며 버튼은 항상 남는다. 문단마다 여백을 두고, 타이핑 중에도 전체 문장의 공간을 예약해 줄바꿈 흔들림을 줄였다.
- 한 번에 읽기, Escape 닫기, 네이티브 모달, 열고 닫을 때 포커스 이동을 제공한다. 움직임 줄이기 환경에서는 즉시 전체 글을 보여 준다.
- UI의 메이플스토리체를 Pretendard Variable로 교체했다. 제목·본문·버튼의 굵기를 구분하며 입력은 16px 이상이다. 기록에는 기존 Noto Serif KR을 유지한다.
- 이동 화면의 중복 목적지 카드를 없앴다. 거점 순서와 거리 안내는 위에 한 번만 표시하며, 내 정보·메뉴·위치 버튼을 작게 정리해 지도 공간을 확보했다.
- 임무 선택지, 자물쇠, 완료 화면을 종이색과 녹색 계열로 맞추고 작은 화면의 스크롤을 보정했다.
- 눈 높이, 눈썹 기울기, 입꼬리, 볼 너비를 부드럽게 변형한다. 참가자 식별자에서 같은 값을 계산하여 모든 폰에서 같은 팀원의 모습이 유지된다. 원본 GLB와 UV·뼈대는 보존한다.
- `/design-review`에서 네 표정과 두 서체, 기록 화면을 직접 확인할 수 있다. 게임 방이나 진행 상태를 변경하지 않는 검토 페이지다.

## 서체 조사
- [Pretendard 공식 문서](https://github.com/orioncactus/pretendard/blob/main/packages/pretendard/README.md): 다국어 UI, 9가지 굵기 및 가변 글꼴 지원. UI의 짧은 안내와 숫자를 정돈하기 위해 채택했다.
- [고운바탕 공식 저장소](https://github.com/yangheeryu/Gowun-Batang): 친근한 필기 성격도 검토했다. 이번에는 기록 화면의 기존 명조 분위기를 유지하며 크기·행간·문단 구조를 먼저 고쳤다.
- Pretendard v1.3.9 WOFF2는 공식 저장소에서 내려받아 앱에서 제공한다. OFL을 `web/public/fonts/Pretendard-OFL.txt`에 동봉했다. 브라우저가 외부 폰트 CDN을 요청하지 않는다.

## 범위
로컬 브랜치의 미리보기이다. 공유 배포·PR·서버 코스 변경은 하지 않았다. 2D 대체 이미지의 얼굴은 기존 이미지이며, 변주는 실제 3D 장병에 적용된다. 혼자 데모는 기존 두 거점, 4인 코스는 정문→용봉관→추모의 벽→봉지 흐름이다.

## 검증
- 프로덕션 빌드 및 TypeScript 검사 통과.
- Vitest 39파일 355검사 통과. 표정 식 조정 후 얼굴·변주 6검사 재통과.
- Chrome: 내레이션, 작은 화면의 이동·임무·자물쇠·완료 버튼, 4인 협동 카드, 안내·음량 설정, 두 거점 실제 UI 풀이, 4거점 추모·회고·결과 복원 검사 통과.
- WebKit: 내레이션과 키보드 복귀, 작은 화면 주요 버튼, 협동 카드, 안내·음량 설정, 4거점 추모·회고·결과 복원 검사 통과.
- 320×568, 390×844, 844×390, 1440×900 화면과 안내 창의 768px 폭을 점검했다. 접근성 자동 검사는 홈·설정·기록 모달·협동 카드의 대상으로 수행했다.
- 4거점 검사는 테스트 방에서 앞부분을 API로 준비하고 추모·회고 UI를 조작한다. 실제 현장 GPS나 실물 iPhone 사용 검증은 이번 범위에 포함하지 않는다.
- Safari의 마우스 클릭은 버튼을 포커스하지 않는 기본 동작이 있어, 포커스 복귀 검사는 키보드 Enter로 모달을 열도록 구성했다. 검사 조건을 수정한 후 통과했다.
