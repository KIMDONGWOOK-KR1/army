# 새 코스 자동 시연

첫 화면의 **자동 시연 보기**를 누른다. 현재 미리보기는 http://localhost:3013/ 이다. 이미 혼자 체험 중이면 작전 메뉴의 **처음부터 자동 시연**으로 새 시연 방을 만든다.

정문 → 용봉관 → 기존 추모의 벽 → 봉지 → 결과까지 한 브라우저에서 네 보직을 교대하며 진행한다. 기본 조작 간격은 1.8초, 지도 이동 장면은 6초, 묵념은 최소 12초 기다린다. 나레이션과 도착 연출을 켰다면 해당 연출이 끝날 때까지 기다린다. 대략 4~6분이며 서버 응답과 나레이션 길이에 따라 달라진다.

**실제 정답을 풀어 주는 기능은 아니다.** 기존 1→3단계 힌트와 해설 확인, 조사 보고, 해설 복원 절차를 시연한다. 답·비밀 키를 프런트엔드에 추가하지 않았다. 봉지 회고와 공동 근거에는 '자동 시연 예시'를 명시한다. 공동 낱말은 공개 선택지 중 일부를 고르며 정해진 정답은 없다.

상단에서 일시정지·계속·직접 체험하기를 고른다. 화면을 직접 클릭하거나 키보드를 사용하면 자동 진행이 멈춘다. 탭을 숨겨도 멈춘다. 직접 진행해서 화면이 바뀐 경우 다시 자동 진행하면 예상 화면이 나타나지 않아 정지할 수 있다. 이때는 직접 체험을 이어가거나 메뉴에서 새 시연을 시작한다. 새로고침 뒤에는 자동 진행이 재개되지 않는다. 일반 4인 방에는 시연 제어가 붙지 않는다.

기존 코스 5개, 추모의 벽 구현, 서버 정답 검증, 음원, 3D 지도는 이번 변경에서 수정하지 않았다. 이전 커밋의 MINO 코스·단서 연출·드래그 UI에 자동 시연을 연결한 변경이다.

## 확인 범위

- `npx tsc --noEmit -p .`: 통과.
- `npx vitest run`: 44개 파일, 377개 시험 통과.
- `NEXT_PUBLIC_BACKEND=local npm run build`: 통과.
- 초기 자동 시연 시험에서 호출명 공백 검증 실패와 거점 전환 중 `STALE_STAGE` 조회 오류로 인한 정지를 발견해 수정했다. 후자는 재현 단위 시험 3개를 추가했다. 기존 묵념 연출이 자동으로 끝나 버튼이 사라지는 경우에도 헌화 화면을 인식해 계속 진행하도록 보완했다.
- 최종 Playwright 순차 실행: **6/6 통과**(3.8분). Chrome·WebKit 각각 자동 완주·도착 연출/직접 조작 전환·네 독립 브라우저 세션의 정상 풀이를 확인했다. 결과 화면의 회고 4/4·동의 4/4와 새로고침 복원, 320/430px 레이아웃을 검사했다. 실제 폰 4대를 사용한 시험은 아니다.
- 자동 완주 브라우저 시험은 화면 타이머만 가속한다. 서버 요청·보직 전환·힌트·보고·헌화·회고·동의는 실제 로컬 API로 진행한다. 도착 연출과 직접 조작 전환은 별도 실제 시간 시험으로 확인한다.

검증 중 임시 병렬 실행에서는 기존 낱말 드래그 시험이 시간 초과되었고, 묵념 화면 전환 보완 전 자동 시연도 중단되었다. 이를 완료로 계산하지 않고 기본 단일 worker 설정으로 다시 검증했다.

새로운 인물·연도·장소 사실은 추가하지 않았다. 실제 4대의 폰, 현장 보행 경로와 횡단보도, GPS는 이번 자동 시연으로 검증되지 않는다. 영상 파일은 생성하지 않았다.
