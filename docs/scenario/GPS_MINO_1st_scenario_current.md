## 1. 이야기

### 1.1 한 문장 이야기

현재의 탐방팀이 끊어진 교육용 기록 전송을 이어받아, 세 장소의 글·사진·인물 기록을 비교하고 세 장의 사초를 완성

이야기 속 무전기와 ‘기록지원실’은 현재의 탐방을 안내하기 위한 가상 장치이므로 화면속에서 무전기의 고장이나 전송 누락으로 표현이 되는 부분(예를 들어, 갑자기 지지직 거린다던가... 이팩트 효과가 있는 부분에 대해서) 실제 역사에서 일어난 사건을 뜻하지 않는다. 변조 보고서도 오류 탐지 학습을 위해 만든 문장이며, 실제 역사 문서가 변조되었다는 주장이 아니다.

‘사초’는 앱에서 팀이 작성하는 역사 기록 카드의 명칭으로 분명하게 팀원들이 눈으로 확인 가능한 자료들을 기반으로하며, 원본 사료를 발견하거나 훼손된 실제 사료를 복원하는 설정으로 표현하지 않는다.

### 1.2 고정 동선과 서사

**용봉탑 하차·팀 구성 → 정문·민주공원 → 용봉관 → 용봉열사 추모의 벽 → 봉지 집결·종료**

| 구간 | 이야기의 질문 | 결과 |
| --- | --- | --- |
| 용봉탑 | 네 사람은 어떻게 함께 조사할 것인가? | 역할 배정·준비·출발 |
| 정문·민주공원 | 이곳에서 무엇이 시작되었는가? | 사초① 시작의 기록 |
| 용봉관 | 그 기록을 어떤 근거로 믿을 수 있는가? | 사초② 검증의 기록 |
| 용봉열사 추모의 벽 | 기록 속에는 어떤 사람들의 삶이 있는가? | 사초③ 사람의 기록 |
| 봉지 | 확인한 기록을 오늘의 언어로 어떻게 남길 것인가? | 사초 3개 결합·공동 기록·결과 |

준비 5분, 정문 8분, 용봉관 10분, 추모의 벽 약 6분, 마무리 집결 4분을 기준으로 삼는다. 이동 시간을 포함하여 약 40분-1시간 내짓 운영을 목표로 하되 실제 보행 동선과 관람 여건을 답사하여 조정한다. 교육시간에서 벗어나지 않는 선에서 거점에서 시간 압박을 주지 않는다.

### 1.3 대본 표기

- **나레이션:** 녹음하거나 자막으로 보여줄 교육용 창작 문구.
- **안내 통신:** 가상 기록지원실의 음성. 실제 당시 무전·증언·인물 발언이 아니다.
- **화면:** 참가자 화면의 문구와 조작.
- **효과:** 짧은 시각·음향 연출. 모든 음성은 같은 내용의 자막을 제공한다.
- **진행 조건:** 장면을 시작하거나 다음 장면으로 넘어가는 조건.
- **정답·해설:** 진행자용 내용. 참가자에게는 제출 이후 또는 해설 요청 시 공개한다.

나레이션은 참여자가 멈춰 선 뒤 재생한다. !이동 중!에는 긴 음성, 퍼즐, 촬영 요청을 실행하지 않는다. 피해자의 목소리 모사, 비명·총성·폭발음, 당시 현장을 사실처럼 재현한 가상 음성은 헷갈릴 수 있으므로 사용하지 않는다.

### 1.4 공통 협동 규칙

| 역할 | 고유 정보 | 맡는 행동 |
| --- | --- | --- |
| 지휘관 | 통신 주파수, 전체 보고서, 최종 제출 화면 | 조사 요청, 보고 종합, 근거 선택, 힌트 요청, 다음 이동 개시 |
| 정찰원 | 부분 사진, 관찰 항목, 지도 | 실제 장소·형태·이름 확인, 허용된 촬영 또는 관찰 메모 |
| 통신원 | 통신 복원 화면, 자료의 전달 내용 | 잡음 복원, 핵심 단어 확인, 정보의 의미 전달 |
| 암호해독관 | 비교 문장, 출처 상태, 수정 과제 | 오류 탐지, 출처 대조, 근거의 한계 확인 |

지휘관 화면에는 팀원의 도착·접속·미션 완료·보고 여부가 표시된다. 정답과 완료 숫자는 자동 전달하지 않는다. 각자는 “확인한 내용 → 확인한 출처 → 남은 불확실성” 순서로 말하고, 지휘관이 내용을 종합할 수 있도록 한다.

조사 결과에는 출처와 관찰 내용을 남긴다. GPS 도착이나 사진 촬영만으로 역사적 사실을 검증했다고 판정하지 않는다. 사진은 증거 메모이며 내용의 자동 진위 판정 기능은 구현가능 여부에 따라 판단하기에 섣불리 판정하지 않는다.

현장 기록에 필요한 정보가 없거나 접근할 수 없으면 공식 디지털 자료로 힌트 및 문제를 대체한다. 결과에는 `현장 확인`, `공식 디지털 자료 확인`, `해설 확인 후 복원`을 구분해 남긴다.

공통 확인 방식·확인한 출처·연결할 자료 선택기는 사용하지 않는다. 각 문항 자체에서 요구하는 기록·근거·자료 연결 항목은 유지하며, 수집하지 않은 확인 방식을 현장 확인으로 간주하지 않는다.

### 1.5 힌트와 재시도

| 단계 | 제공 내용 | 처리 |
| --- | --- | --- |
| 1단계 | 무엇을 살필지 알려주는 질문 | 감점 0점 |
| 2단계 | 확인할 대상·문장·정보를 좁혀 줌 | 추가 감점 10점 |
| 3단계 | 해당 역할의 미완료 문제 전체를 해설 공개·해설 완료 처리 | 추가 감점 10점(누적 20점) |

힌트는 지휘관이 역할을 선택해 요청하고 해당 팀원에게 전달한다. 새 헌화 코스의 추모의 벽에는 문제·힌트·점수를 표시하지 않는다. 시간 종료로 교육 내용을 숨기지 않는다.

정문·용봉관의 무힌트 보너스는 0점이다. 3단계 힌트는 이미 완료한 문제와 제출 기록을 유지하며 해당 역할의 미완료 문제 전체만 해설 완료로 처리한다. 해설 완료만으로 완료 숫자를 지급하지 않는다. 시간 점수와 팀 랭킹은 요구사항으로 유지하되 계산식·공개 범위가 확정되지 않아 현재 구현에서는 산출하지 않고 null로 둔다.

## 2. 프롤로그 — 용봉탑에서 네 사람이 만나다

### P-01. 하차와 시작

**진행 조건:** 버스에서 내려 보행을 방해하지 않는 안전한 집결 지점에 모였다.

**효과:** 종이 기록철이 열리는 작은 애니메이션. 소리 활성화 버튼을 누른 경우에만 낮은 잡음이 짧게 재생된다.

**나레이션:**

> 용봉탑 앞에 네 사람이 모였다. 휴대전화 속 기록철을 열자, 부서진 무전기가 지지직거린다. 끊어진 신호 사이로 짧은 안내가 들려온다.

**안내 통신:**

> 기록지원실입니다. 오늘 조사할 기록은 세 부분입니다. 사건의 시작, 기록의 근거, 그리고 그 안에 남은 사람들의 삶. 네 사람이 서로 다른 정보를 확인하고 함께 한 장씩 완성해 주십시오.

**화면:** `방 만들기` / `참가 코드로 입장`.

방장은 4자리 코드·참가 QR·링크를 공유한다. 네 명의 접속이 확인되면 방장에게 `역할 배정 시작`이 열린다. 대기 중에는 다른 팀원의 정답이나 향후 거점 문제를 보여주지 않는다.

### P-02. 보직 공개

**진행 조건:** 네 명 접속 후 방장이 역할 배정을 시작했다.

**효과:** 모든 화면에 3 → 2 → 1. 인식표가 한 번 뒤집힌다.

**나레이션:**

> 네 사람의 화면에 서로 다른 임무가 도착했다. 누구도 혼자서는 모든 기록을 볼 수 없다. 각자가 확인한 것을 말하고, 다른 사람의 근거를 듣는 순간 조사가 시작된다.

| 공개 대상 | 역할별 나레이션 |
| --- | --- |
| 지휘관 | “당신은 보고를 모으는 사람입니다. 가장 먼저 답을 고르기보다, 누가 무엇을 근거로 말하는지 확인하십시오.” |
| 정찰원 | “당신은 화면과 장소를 잇는 사람입니다. 사진의 일부를 실제 모습과 비교하고, 이름과 설명을 직접 확인하십시오.” |
| 통신원 | “당신은 끊어진 정보를 잇는 사람입니다. 들린 단어를 확인하고, 의미가 달라지지 않도록 전달하십시오.” |
| 암호해독관 | “당신은 기록 사이의 차이를 살피는 사람입니다. 낯선 표현을 의심하고, 고칠 때에는 근거를 함께 남기십시오.” |

참가자는 최초 배정된 보직을 게임 내내 유지한다. 참가자 간 보직 교환·겸임은 허용하지 않으며, 새로고침하거나 재접속해도 최초 보직을 유지한다.

### P-03. 준비와 출발

**화면:** 위치·카메라·소리·화면 유지 점검. 각 권한은 해당 버튼을 누른 직후 요청하며 모든 확인이 끝난 후 다음 화면으로 넘어간다.

**나레이션:**

> 기록을 찾는 데 필요한 준비를 확인한다. 사용할 수 없는 기능은 다른 방법으로 이어갈 수 있다. 준비가 끝났다면 첫 번째 장소, 정문으로 향하자.

**역할별 출발 확인:**

- 지휘관: `팀원의 준비 상태를 확인했습니다`.
- 정찰원: `이동 경로와 안전 안내를 확인했습니다`.
- 통신원: `소리 또는 자막을 확인했습니다`.
- 암호해독관: `출처를 함께 기록하는 방법을 확인했습니다`.

**진행 조건:** 네 명 준비 완료 → 지휘관 `정문으로 출발`.

**이동 화면:** “이동 중에는 화면을 내려놓으세요. 멈춘 뒤 방향과 거리를 확인하세요.”

## 3. 미션 1 — 정문·민주공원 / 시작의 기록

### G-00. 도착과 보고서 수신

**진행 조건:** 실제 GPS 코스에서는 네 명이 각각 확정된 목표 좌표의 반경 10m 안에서 유효 위치 표본 3개의 평균으로 5초 동안 머물러 도착을 보고해야 한다. 전원 GPS 도착 전에는 미션 진입·문제 제출·보고·자물쇠 개방을 허용하지 않는다. GPS 권한 거부·측위 오류·미확정 좌표는 QR, 지휘관 수동 확인, 진행자 확인으로 우회하지 않는다. 방 합류용 QR은 도착 확인과 별개다.

**효과:** 정지한 화면 위로 종이 보고서가 펼쳐진다. 첫 진입에만 낮은 잡음을 짧게 재생한다.

**공통 나레이션:**

> 정문에 도착하자 무전기에서 다시 신호가 잡힌다.
> 상황 보고서가 도착했다. 시간과 장소가 적혀 있다.
> **각자 맡은 임무를 확인하라.**

공통 화면을 넘기면 각자 본인 역할의 개인 임무 나레이션이 이어진다. 개인 나레이션은 인증된 본인의 `self.mission.intro`에서만 읽으며 다른 역할의 응답이나 공통 화면에 포함하지 않는다. 본인 안내를 넘긴 뒤 문제 화면으로 진입한다.

**화면:** `시작의 기록을 복원하라` / “무엇을 확인했고, 어디에서 확인했는지 함께 보고하세요.”

진행은 `지휘관 주파수 전달 → 통신원의 탐색 단서 복원 → 정찰원의 조형물 확인 → 통신원의 가치 확인`으로 이어진다. 암호해독관은 처음부터 사건 기록을 독립적으로 조사한다. 지휘관의 최종 판정은 보고를 받은 뒤 진행한다.

### G-01. 지휘관 — 잘못된 보고를 판별하라

**역할 진입 나레이션:**

> 먼저 통신원에게 주파수를 전달하라.
> **현장 기록과 동료들의 보고를 대조해, 사건의 순서와 보고서의 오류를 바로잡아라.**

**받는 정보:** 게임용 가상 주파수 `96.8`, 아래 보고서, 사건 카드 네 장. 주파수는 실제 무선 통신이나 역사적 수치를 의미하지 않는다.

**문제 화면:**

> 통신원에게 주파수를 말로 전달하십시오. 팀원의 보고를 들은 뒤 보고서의 진위를 판단하고 사건 순서를 복원하십시오.

| 미확인 보고서 | 정답 |
| --- | --- |
| 학생들은 5월 18일 오후에 정문에 모였다. | 거짓 |
| 학생들은 사전에 나눈 약속에 따라 모였다. | 사실 |
| 정문 충돌 이후 학생들은 중앙도서관으로 이동했다. | 거짓 |
| ‘피어나다’의 세 꽃잎은 민주·인권·평화를 표현한다. | 사실 |

**해결 순서:**

1. 통신원에게 “주파수는 96.8이야”라고 전달한다.
2. 암호해독관에게 시각·집결 이유·이동 방향 조사를 요청한다.
3. 정찰원과 통신원에게 조형물의 이름·형태·의미를 보고받는다.
4. 네 문장을 판정하고, 사건 카드와 관련 근거를 연결한다.

**사건 카드 정답:** 계엄 확대와 대학 통제 → 약속에 따른 정문 집결 → 출입을 막는 계엄군과 대치·충돌 → 금남로 방향 이동. 이는 학습용으로 간추린 순서다. 대학 통제가 학생들의 집결 이후 시작된 것처럼 배열하지 않는다. [민주길 공식근거](https://518trail.jnu.ac.kr/SubPage.aspx?PageCode=K20200)

**힌트 대사:**

- 1단계: “시간, 모인 이유, 이동 방향을 따로 물어보십시오. 조형물의 의미도 한 사람의 추측으로 결정하지 마십시오.”
- 2단계: “사건의 세 항목은 암호해독관에게, 조형물의 의미는 정찰원과 통신원에게 확인하십시오.”
- 3단계: “판정은 거짓·사실·거짓·사실입니다. 사건 카드는 통제→집결→충돌→시내 이동 순서로 놓고 관련 설명을 읽으십시오.”

**재시도 나레이션:**

> 보고 사이에 아직 맞지 않는 부분이 남아 있다. 마지막으로 고른 문장과 그 근거를 다시 나란히 놓아보자.

**완료 조건:** 진위 판정·순서 배열·근거 직접 작성을 완료한다. 완료 숫자 `4`가 본인에게만 표시된다. 사건 순서는 자동 채점하고 근거는 필수 자유 기록으로 제출한다. 원문에 없는 근거 선택지나 정답 짝은 만들지 않는다.

**완료 나레이션:**

> 세 사람의 보고가 한 흐름으로 이어졌다. 이제 각자의 확인 결과를 마지막으로 모을 차례다.

### G-02. 정찰원 — 사진 속 조형물을 찾아라

**역할 진입 나레이션:**

> 사진 조각과 통신원이 전한 문장은 같은 대상을 가리킨다.
> **현장에서 대상을 찾아 이름과 특징을 확인하고, 관찰한 내용을 팀에 전하라.**

**받는 정보:** ‘피어나다’ 부분 사진. 실제 촬영본의 사용 허가를 확인하여 제공하며, 정확한 모양을 확인하기 전 임의 생성 사진을 정답 자료로 쓰지 않는다.

**문제 화면:**

> 부분 사진과 통신원의 단서를 이용해 조형물을 찾으십시오. 작품 이름, 꽃잎 수, 이름을 확인한 출처를 기록하십시오.

**해결 순서:**

1. 통신원이 전달하는 “세 꽃잎이 펼쳐지는 형태”를 듣는다.
2. 안전한 관찰 지점에서 사진과 실제 형태를 비교한다.
3. 안내문 또는 공식 설명에서 작품 이름을 확인한다.
4. 허용된 촬영 또는 관찰 메모를 남기고, 통신원에게 안내 위치를 알려준다.

**발견 직후 나레이션:**

> 화면에서 잘려 있던 모습이 눈앞에서 이어진다. 닮은 모양을 찾았다면, 이제 이름이 맞는지 설명을 확인하자.

**정답:** 작품 이름 `피어나다`, 표현된 꽃잎 `3개`. 불꽃을 찾거나 불꽃 수를 세는 과제로 만들지 않는다. [피어나다 근거](https://518trail.jnu.ac.kr/SubPage.aspx?PageCode=K20200)

**힌트 대사:**

- 1단계: “색보다 반복되는 형태를 살펴보십시오.”
- 2단계: “통신원이 전한 ‘세 꽃잎’과 주변 조형물의 형태를 비교하십시오.”
- 3단계: “‘피어나다’를 찾아 작품 이름과 형태를 대조하십시오. 관찰 메모를 남기면 촬영 없이도 이어갈 수 있습니다.”

**보고 예시:** “피어나다를 찾았습니다. 세 꽃잎 형태이며, 작품 이름은 이 안내에서 확인했습니다.”

**완료 조건:** 이름·형태·출처 기록 및 관찰 자료 제출. 완료 숫자 `1` 공개.

**완료 나레이션:**

> 장소에서 확인한 첫 번째 증거가 기록철에 들어왔다. 찾은 이름과 설명의 위치를 동료에게 전하자.

### G-03. 통신원 — 잡음 속 세 단어를 복원하라

**역할 진입 나레이션:**

> 지휘관에게 받은 주파수로 무전을 연결하라.
> **복원한 문장을 정찰원에게 전하고, 정찰원의 관찰과 연결되는 핵심 낱말을 찾아라.**

**받는 정보:** 주파수 다이얼. 목표 값은 본인 화면에 처음부터 표시하지 않는다.

**문제 1:** 지휘관에게 받은 가상 주파수로 다이얼을 맞춘다. 정답 `96.8`에 도달하면 짧은 잡음이 잦아들고 다음 교육용 음성이 열린다.

**복원된 안내 통신:**

> 탐색 단서입니다. 세 꽃잎이 펼쳐지는 조형물을 확인하십시오. 작품이 표현하는 세 가지 가치는 현장의 설명에서 찾을 수 있습니다.

**중간 행동:** 이 형태 단서를 정찰원에게 말로 전달한다. 정찰원의 조형물 발견 전에도 통신 복원 자체는 완료할 수 있다.

**정찰원 보고 후 나레이션:**

> 정찰원이 조형물을 찾았다. 이제 들린 단서를 작품의 설명과 연결할 차례다. 세 꽃잎이 무엇을 표현하는지 확인하자.

**문제 2:** “이 작품이 표현하는 세 가지 가치는 ______, ______, ______이다.”

**해결 순서:** 주파수 복원 → 형태 단서 전달 → 정찰원이 찾은 안내문 또는 공식 자료 확인 → 세 단어 입력 → 지휘관 보고.

**정답:** `민주 · 인권 · 평화`. 입력 순서는 달라도 인정한다. 이 작품의 상징을 현재의 기념 조형물 설명으로 다루며, 조형물이 1980년 당시 존재했다고 서술하지 않는다.

**힌트 대사:**

- 1단계: “형태의 이름이 아니라 작품이 표현하는 가치를 찾으십시오.”
- 2단계: “세 단어의 초성은 ㅁㅈ·ㅇㄱ·ㅍㅎ입니다.”
- 3단계: “민주·인권·평화입니다. 세 꽃잎과 가치가 연결되는 설명을 읽고 지휘관에게 전하십시오.”

**보고 예시:** “확인한 세 가치는 민주·인권·평화입니다. 조형물 설명에서 확인했습니다.”

**완료 조건:** 통신 복원·세 단어·출처 확인. 완료 숫자 `7` 공개. 음성 사용이 어려우면 동일한 자막으로 진행한다.

**완료 나레이션:**

> 잡음 속 단어가 장소의 설명과 만났다. 들은 내용과 확인한 내용을 함께 전달하자.

### G-04. 암호해독관 — 세 군데가 바뀐 문장을 복원하라

**역할 진입 나레이션:**

> 사건 기록에는 사실과 다른 내용이 섞여 있다.
> **현장 안내와 공식 기록을 대조해 잘못된 부분을 고르고, 바르게 고쳐라.**

**문제 화면 — 교육용 변조 보고서:**

> 1980년 5월 18일 **오후 2시**, 학생들은 **예정된 교내 행사**에 참여하려고 정문에 모였다. 충돌 이후에는 **중앙도서관**으로 이동했다.

**과제:** 의심되는 표현 세 곳을 선택하고 현장 안내 또는 공식 자료를 이용해 수정한다.

**해결 순서:** 시간·이유·이동 장소 표시 → 안내 기록 대조 → 수정 내용 입력 → 출처 기록 → 지휘관 보고.

**근거를 찾았을 때 나레이션:**

> 설명 속에 보고서와 다른 표현이 보인다. 다르다는 사실을 찾았다면, 무엇을 기준으로 고쳤는지도 남기자.

| 바뀐 표현 | 정답 |
| --- | --- |
| 오후 2시 | 오전 10시 |
| 예정된 교내 행사 | 박관현 총학생회장과 나눈 약속에 따른 집결 |
| 중앙도서관 | 금남로 방향 |

정답은 공식 정문 설명을 기준으로 한다. 현장 안내판에서 모두 확인할 수 있는지는 별도 대조가 필요하다. [정문 근거](https://518trail.jnu.ac.kr/SubPage.aspx?PageCode=K20200)

**힌트 대사:**

- 1단계: “언제, 왜, 어디로 이동했는지를 확인하십시오.”
- 2단계: “‘오후 2시’, ‘교내 행사’, ‘중앙도서관’을 안내 기록과 대조하십시오.”
- 3단계: “오전 10시, 사전 약속, 금남로 방향으로 수정합니다. 세 항목의 근거를 읽고 확인한 출처를 남기십시오.”

**보고 예시:** “시간·이유·이동 방향 세 곳을 수정했습니다. 근거는 정문 공식 설명에서 확인했습니다.”

**완료 조건:** 오류 세 곳·수정 내용·출처 확인. 완료 숫자 `2` 공개.

**완료 나레이션:**

> 수정한 문장 옆에 확인한 출처가 남았다. 이제 왜 고쳤는지 설명할 수 있다.

### G-05. 보고 집결과 자물쇠

**진행 조건:** 네 역할 조사 완료. 각자 보고 후 `보고 완료`를 누르고, 지휘관이 보고의 핵심과 근거를 확인한다. 숫자 입력만으로 미완료 조사를 건너뛰지 못한다.

**나레이션:**

> 네 사람의 기록이 모였다. 직접 본 모습, 복원한 단어, 수정한 문장, 사건의 순서가 한 장의 기록을 이룬다. 각자가 받은 확인 숫자를 지휘관에게 전하자.

| 입력 순서 | 지휘관 | 정찰원 | 통신원 | 암호해독관 |
| --- | --- | --- | --- | --- |
| 시연용 완료 숫자 | 4 | 1 | 7 | 2 |

**정답:** `4172`. 숫자는 게임용 확인 값이며 역사적 수치나 인물 이름에서 추출하지 않는다.

**잘못 입력했을 때 안내:** “역할 순서와 전달받은 숫자를 다시 확인하세요. 지휘관→정찰원→통신원→암호해독관 순서입니다.”

**성공 효과:** 지휘관 화면에서만 작은 기록철 열림 효과. 모든 역할 화면에는 완료 상태와 사초를 표시한다.

### G-06. 사초①과 다음 이동

**사초① — 시작의 기록:**

> 우리는 정문에서 사건의 시간과 집결 이유, 이후 이동 방향을 확인했다. 잘못된 표현을 고칠 때에는 현장의 설명과 공식 기록을 근거로 삼았다.

카드에는 복원한 사건 순서의 검증 완료 여부(정답 배열 제외), 조형물 관찰, 사용한 출처, 확인 방식을 함께 저장한다. 현대 조형물의 상징 설명과 1980년 사건 기록은 항목을 나누어 보여준다. 공통 출처·확인 방식은 별도로 입력받지 않으며, 기존 기록이 없으면 미수집 상태로 둔다. 문항 자체의 근거·출처 기록은 유지한다.

**나레이션:**

> 첫 번째 사초가 완성되었다. 하지만 한 장의 보고서를 바로잡았다고 모든 기록을 판단할 수 있는 것은 아니다. 다음 장소에서는 자료마다 무엇을 말해주고 무엇을 말해주지 않는지 살펴보자.

**안내 통신:**

> 다음 조사 장소는 용봉관입니다. 도착하면 기록의 출처와 쓰임을 확인하십시오.

**진행 조건:** 지휘관 `용봉관으로 이동` → 미션 화면 잠금 → 이동·안전 안내.

## 4. 미션 2 — 용봉관 / 검증의 기록

### Y-00. 도착과 관람 안내

**진행 조건:** 네 사람 도착 후 관람 가능 여부와 촬영 제한을 확인한다. 실내 도착은 GPS만 강제하지 않고 QR 또는 진행자 확인을 허용한다.

**화면:** 전시물을 만지지 않기 / 뛰거나 큰 소리로 말하지 않기 / 촬영 제한 확인 / 화면보다 실제 기록 먼저 관찰.

**나레이션:**

> 용봉관 앞에서 새로운 자료 목록이 열린다. 건물의 모습, 글로 남긴 요구, 사진에 담긴 장면, 시간이 지난 뒤의 증언. 모두 기록이지만, 각각 확인할 수 있는 내용은 다르다.

**안내 통신:**

> 두 번째 조사입니다. 자료가 있다는 이유만으로 모든 주장을 확인했다고 쓰지 마십시오. 무엇을 알 수 있고, 무엇을 더 확인해야 하는지 구분해 주십시오.

실내에서는 음향을 자동으로 낮추고 자막을 기본 제공한다. 자료 유형 카드는 학습용이며, 특정 문서가 현재 실내에 전시되어 있다고 단정하지 않는다. 실제 조사 자료는 방문 시 확인한 전시물 또는 출처·사용 권한을 확인한 공식 디지털 자료로 지정한다.

**현행 앱 진행 규칙:** 외부 대체 모드는 네 명 모두 도착한 뒤 용봉관 완료 전 언제든 지휘관이 선택할 수 있다. 전환해도 기존 기록·보고·힌트·감점·자물쇠 시도 횟수를 유지하며 실내 모드로 되돌리지 않는다. 사초②·완료 결과·기록첩에는 「외부 대체 조사 · 실내 관람 아님」을 표시한다.

### Y-01. 정찰원 — 과거 사진과 현재 건물을 연결하라

**역할 진입 나레이션:**

> 화면에 오래된 건물 사진이 펼쳐진다. 지금 눈앞의 건물과 어떤 부분이 닮아 있을까. 모양으로 확인할 수 있는 것과 설명을 읽어야 알 수 있는 것을 나누어 보자.

**받는 정보:** 출처가 확인된 용봉관 과거 사진, 외형 선택지, 과거 용도 입력 칸. 원본의 촬영 시점을 모르면 임의의 날짜를 붙이지 않는다.

**문제 화면:**

> 과거 사진과 현재 건물에서 공통으로 확인되는 특징 두 가지를 선택하십시오. 이 건물의 과거 용도도 확인하십시오.

**선택지:** 중앙의 높은 탑상형 구조 / 좌우 대칭 / 전체가 원형인 건물 / 정면 전체가 유리로 된 외벽.

**해결 순서:**

1. 보행을 방해하지 않는 위치에 멈춰 건물 정면을 관찰한다.
2. 사진과 현재 모습에서 중앙부와 양쪽 부분을 비교한다.
3. 외형 특징 두 가지를 선택한다.
4. 과거 용도는 현장 안내 또는 공식 설명으로 확인한다.

**비교 중 나레이션:**

> 중앙과 양쪽의 배치가 눈에 들어온다. 그러나 건물의 모습만으로 과거에 어떤 일을 하던 곳인지까지 알 수는 없다. 이제 설명을 찾아보자.

**정답:** 중앙의 탑상형 구조, 좌우 대칭 / 과거 용도는 대학 본부. 공식 안내는 1957년 12월부터 1996년 5월까지 대학 본부로 사용되었다고 설명한다. 기간은 해설로 제공하며 암기 입력을 요구하지 않는다. [공식 근거 S2](https://518trail.jnu.ac.kr/SubPage.aspx?PageCode=K21000)

**힌트 대사:**

- 1단계: “건물 가운데와 양쪽의 관계를 살펴보십시오.”
- 2단계: “중앙부의 높이와 좌우 배치를 비교하십시오. 과거 용도는 안내 자료에서 찾으십시오.”
- 3단계: “중앙 탑상형 구조와 좌우 대칭이 정답입니다. 과거 용도는 대학 본부입니다. 관찰한 것과 읽어서 확인한 것을 나누어 기록하십시오.”

**보고 예시:** “탑상형 구조와 좌우 대칭은 외형에서 확인했습니다. 과거 대학 본부였다는 내용은 공식 안내에서 확인했습니다.”

**완료 조건:** 외형 두 항목·과거 용도·각 근거 확인. 완료 숫자 `3` 공개.

**완료 나레이션:**

> 직접 본 사실과 설명으로 확인한 사실이 구분되어 기록되었다. 두 근거를 함께 지휘관에게 전달하자.

### Y-02. 통신원 — 자료마다 전하는 정보를 구분하라

**역할 진입 나레이션:**

> 이번에 도착한 것은 음성이 아니라 네 종류의 기록이다. 어떤 것은 요구를 밝히고, 어떤 것은 논의를 남긴다. 자료가 맡은 역할을 읽어보자.

**받는 정보:** 성명서·전단지·회의록·사진 및 영상의 자료 유형 카드와 기능 카드. 이 카드는 유형 학습 자료로 표시하고 실제 전시 문서의 모사본처럼 꾸미지 않는다.

**문제 1:** “자료와 주된 기능을 연결하십시오.”

| 자료 | 정답 |
| --- | --- |
| 성명서 | 작성 주체의 공식 입장과 요구를 밝힌다. |
| 전단지 | 여러 사람에게 정보와 주장을 전달한다. |
| 회의록 | 논의 내용과 결정 과정을 남긴다. |
| 사진·영상 | 촬영된 현장의 모습을 남긴다. |

**문제 2:** “같은 사건을 여러 종류의 자료로 확인해야 하는 이유는 무엇입니까?”

1. 오래된 자료는 모두 틀리기 때문이다.
2. 자료가 많으면 출처를 확인하지 않아도 되기 때문이다.
3. 하나의 자료만으로 모든 사실을 확인하기 어렵기 때문이다.
4. 사진은 언제나 모든 사실을 보여주기 때문이다.

**정답:** 3번.

**현장 연결 과제:** 전시 또는 제공된 공식 디지털 자료에서 한 점을 골라 `제목 / 자료 유형 / 표시된 작성 시기 / 소장처 또는 제공기관 / 알 수 있는 내용 한 가지`를 기록한다. 확인되지 않는 항목에는 ‘확인 불가’를 적는다. 자료의 제목은 선택에 따라 달라지므로 고정 정답으로 만들지 않는다.

**자료를 골랐을 때 나레이션:**

> 하나의 기록을 골랐다. 무엇이 적혀 있는지 읽고, 누가 언제 만든 자료인지도 살펴보자. 보이지 않는 정보는 추측해서 채우지 않아도 된다.

**해결 순서:** 유형 연결 → 이유 선택 → 실제 자료 한 점 관찰 → 자료 정보와 확인 범위를 암호해독관에게 전달 → 지휘관 보고.

**현행 앱 기록·전달 규칙:** 자료 기록은 제목·유형·생산 시점·제공자·알 수 있는 내용의 다섯 칸을 필수로 입력하며, 확인할 수 없는 칸에는 「확인 불가」를 적는다. 이 기록은 통신원 본인과 전달 대상인 암호해독관에게만 제공하고 지휘관·정찰원·팀 공통 화면에는 공개하지 않는다. 별도의 공통 확인 방식·출처·연결 자료 선택은 요구하지 않는다. 통신원이 자료 기록 없이 3단계 힌트로 완료하면 암호해독관에게 「기록 없음·추가 확인 필요」를 알린다. 실제 자료를 만들어 채우지 않으며, 이미 제출한 기록은 보존한다.

**힌트 대사:**

- 1단계: “누가 누구에게 무엇을 전달하려고 만든 자료인지 생각하십시오.”
- 2단계: “입장과 요구, 정보 전달, 논의와 결정, 현장 모습으로 나누어 보십시오.”
- 3단계: “성명서→입장, 전단지→전달, 회의록→논의, 사진·영상→현장입니다. 한 자료만으로 모든 사실을 알 수 없기 때문에 다른 자료와 비교합니다.”

**보고 예시:** “제가 고른 자료는 ○○입니다. 여기서는 ○○을 확인할 수 있고, 작성 시기는 ○○로 표시되어 있습니다. 표시가 없는 정보는 확인 불가로 남겼습니다.”

**완료 조건:** 연결·이유 선택·관찰 메모·암호해독관에게 자료 정보 전달. 완료 숫자 `8` 공개.

**완료 나레이션:**

> 기록이 말해주는 범위를 정리했다. 남은 빈칸은 다음 확인을 위한 질문이 된다.

### Y-03. 암호해독관 — 무엇을 더 확인해야 하는가

**역할 진입 나레이션:**

> 자료의 내용을 읽었다면 이제 자료의 바깥도 살펴볼 차례다. 작성자, 날짜, 장소, 전해진 과정. 그 정보가 빠졌을 때 판단은 어디에서 멈춰야 할까.

**받는 정보:** 실제 사료가 아니라 자료의 상태를 설명하는 교육용 카드 네 장.

| 카드 | 주어진 상태 |
| --- | --- |
| A | 사건 당시 작성되었고 작성 주체와 날짜가 확인되는 성명서 |
| B | 촬영 장소와 날짜가 표시되지 않은 사진 |
| C | 사건 이후 당사자가 자신의 경험을 회고한 증언 |
| D | 작성자와 근거를 알 수 없는 인터넷 게시글 |

**문제 1:** “각 자료에 필요한 판단을 연결하십시오.”

| 카드 | 정답·해설 |
| --- | --- |
| A | 작성 주체의 입장과 요구를 살펴볼 수 있다. 내용의 사실 여부는 다른 근거와도 비교한다. |
| B | 촬영 시점과 장소를 추가 확인해야 한다. |
| C | 당사자의 경험을 살피되 회고 시점과 다른 기록을 함께 확인한다. |
| D | 출처를 추적하기 전에는 사실의 근거로 확정하지 않는다. |

**문제 2:** “당시에 만들어진 자료라면 그 안의 모든 내용이 무조건 사실이다.” → **X**.

**통신원과 연결되는 과제:** 통신원이 고른 자료의 정보를 받아, 확인한 항목과 빠진 항목을 구분한다. 그 자료만으로 단정할 수 없는 내용 한 가지를 지휘관에게 보고한다.

**해결 순서:** 카드별 확인 정보와 누락 정보 구분 → 필요한 판단 연결 → OX 응답 → 통신원 자료 대조 → 추가 확인이 필요한 내용을 지휘관에게 보고.

**자료 정보를 받았을 때 나레이션:**

> 동료가 읽은 내용과 출처 정보가 도착했다. 어디까지 확인할 수 있는지 함께 살펴보자. ‘아직 모른다’는 판단도 정확한 기록의 일부다.

**힌트 대사:**

- 1단계: “누가, 언제, 어디에서, 어떤 목적으로 만들었는지 살펴보십시오.”
- 2단계: “사진의 촬영 정보, 증언이 이루어진 시기, 게시글의 원출처를 확인하십시오.”
- 3단계: “A도 교차검증이 필요합니다. B는 촬영 정보, C는 회고 맥락, D는 원출처를 확인합니다. OX 정답은 X입니다.”

**보고 예시:** “이 자료에는 ○○ 정보가 없습니다. 따라서 ○○이라고 단정할 수 없으며, 원래 자료 설명이나 소장기관 정보를 더 확인해야 합니다.”

**완료 조건:** 네 판단 연결·OX·통신원 자료의 한계 보고. 완료 숫자 `5` 공개.

**완료 나레이션:**

> 사실로 남길 내용과 추가 확인이 필요한 내용이 구분되었다. 그 경계를 지휘관에게 전달하자.

**진행자 참고:** ‘후대 증언’과 ‘1차 자료’를 무조건 서로 배타적인 항목으로 분류하지 않는다. 당사자의 증언도 연구 질문에 따라 중요한 1차 자료가 될 수 있다. 출처가 명확하다는 사실과 모든 내용이 참이라는 판단을 구분한다.

### Y-04. 지휘관 — 근거에 맞게 최종 보고서를 고쳐라

**역할 진입 나레이션:**

> 세 동료의 보고가 서로 다른 질문에 답하고 있다. 어떤 주장은 확인되었고, 어떤 주장은 근거가 부족하다. 모두 같은 확신으로 기록하지 않도록 문장을 정리하자.

**문제 1:** “세 문장을 사실·거짓·근거 부족으로 분류하고 근거를 선택하십시오.”

| 문장 | 정답 | 사용할 근거 |
| --- | --- | --- |
| 용봉관은 과거 대학 본부로 사용되었다. | 사실 | 정찰원이 확인한 공식 안내 |
| 용봉관은 대학 본부로 사용된 적이 없다. | 거짓 | 위 안내와 충돌함 |
| 날짜·장소 정보가 없는 이 사진은 1980년 5월 18일 전남대에서 촬영되었다. | 근거 부족 | 촬영 정보가 확인되지 않은 교육용 상황 |

세 번째 문장은 자료 상태를 가정한 문제다. 실제 사진에 근거 없는 날짜를 붙여 제공하지 않는다.

**문제 2 — 수정할 초안:**

> 성명서 한 장을 읽었으므로 사건의 모든 사실을 확인했다.

**수정 답안 예시:**

> 성명서에서 작성 주체의 입장과 요구를 확인했다. 사건의 다른 사실은 사진·회의록·증언 등과 비교해야 한다.

**해결 순서:** 건물 용도 보고 확인 → 자료별 기능 보고 확인 → 출처와 한계 보고 확인 → 문장 분류 → 과도한 확신을 담은 초안 수정.

**힌트 대사:**

- 1단계: “주장마다 그것을 뒷받침하는 자료가 있는지 확인하십시오.”
- 2단계: “건물의 과거 용도는 안내 자료로, 사진의 시점은 촬영 정보로 확인해야 합니다.”
- 3단계: “앞의 세 문장은 사실·거짓·근거 부족입니다. 수정 문장에는 성명서로 확인한 범위와 추가 비교가 필요한 내용을 함께 적으십시오.”

**재시도 나레이션:**

> 확인한 범위보다 문장의 범위가 넓다. 어떤 부분까지 말할 수 있는지 동료의 보고를 다시 살펴보자.

**완료 조건:** 분류·근거 연결·수정 문장 완료. 수정 문장에는 ‘자료로 확인한 내용’과 ‘추가 확인할 내용’이 모두 있어야 한다. 완료 숫자 `6` 공개.

**완료 나레이션:**

> 확인한 사실과 남은 질문이 한 보고서에 함께 담겼다. 이제 두 번째 기록을 완성할 수 있다.

### Y-05. 두 번째 자물쇠와 사초②

**진행 조건:** 네 역할 조사·보고 완료 후 숫자를 구두 전달한다.

**나레이션:**

> 이번 기록에는 답뿐 아니라 답을 확인한 방법도 남았다. 각자의 확인 숫자를 모아 두 번째 기록철을 열자.

| 입력 순서 | 지휘관 | 정찰원 | 통신원 | 암호해독관 |
| --- | --- | --- | --- | --- |
| 시연용 완료 숫자 | 6 | 3 | 8 | 5 |

**정답:** `6385`. 역사적 날짜나 인물에서 유래한 숫자가 아니다.

**사초② — 검증의 기록:**

> 우리는 자료의 작성 주체와 시점, 맥락을 살폈다. 한 자료가 보여주는 범위를 확인하고, 다른 자료와 비교했다. 확인되지 않은 내용은 확인되지 않았다고 남겼다.

실제 선택한 자료의 제목·출처·확인 범위·추가 질문을 카드에 보관한다. 외부 대체 모드에서는 실내 관람 완료로 표시하지 않는다.

**나레이션:**

> 두 번째 사초가 완성되었다. 기록을 판단하는 방법을 배웠다면, 이제 그 안에 남은 사람들을 만날 차례다. 다음 장소에서는 화면과 소리를 잠시 낮추고 이름과 삶을 살펴보자.

**진행 조건:** 지휘관 `추모의 벽으로 이동` → 이동·안전 안내.

## 5. 미션 3 — 용봉열사 추모의 벽 / 국화 놓기

2026-10-11 사용자 확정: 이 거점의 기존 개인 문제·보고·공동 기록은 국화 놓기로 교체한다. 봉지의 회고·공동 기록은 유지한다. 아래는 새 `completion.type:tribute` 코스의 흐름이다.

### W-00. 조용한 모드와 도착

네 사람이 모두 도착한 뒤 추모의 벽 소개를 읽는다. GPS 코스는 기준 좌표 35.178197, 126.907996 중심 반경 10m에서 네 명 모두 5초 도착 조건을 충족한다. 모의 도착 검수 코스에서만 네 명이 각각 모의 도착한다. 기준 좌표는 사용자 제공 CSV의 참조 지점이며 실기기 현장 검증은 별도다.

도착부터 자동 효과음·배경음·진동을 멈춘다. 점수·정답·오답·자물쇠·시간 경쟁과 카운트다운을 표시하지 않는다.

### W-01~W-04. 각자의 국화

정찰원·통신원·암호해독관·지휘관 모두 자기 화면에서 `국화 올리기`를 한 번 누른다. 역할에 따른 별도 조사나 문제는 없다. 자기 역할의 국화만 올릴 수 있고, 동료들의 헌화 상태를 함께 본다. 동시에 누를 필요나 시간제한은 없다.

헌화 상태는 서버에 저장되어 새로고침·재접속 후에도 유지된다. 먼저 헌화한 사람은 동료들이 마음을 전하는 동안 기다린다. 추가 확인 방식·출처·근거 입력이나 별도 보고는 요구하지 않는다.

### W-05. 네 송이의 국화와 사초③

네 명 모두 국화를 올리면 서버가 거점을 완료한다. 공동 문장 작성·읽음 확인 대신 네 사람의 헌화로 사초③을 완성하며 기록첩·결과에는 `헌화 완료`로 표시한다. 국화 개수는 함께한 상태를 보여 주며 점수가 아니다.

**화면 선택:** 조용히 머무르기는 선택형 로컬 휴식이다. 약 10초 뒤 이동 준비가 다시 표시되며 사용자는 언제든 먼저 끝낼 수 있다. 숫자 카운트다운이나 서버 완료 조건으로 사용하지 않는다.

### W-06. 봉지로 이동

헌화 완료 후 지휘관이 다음 거점 이동을 실행한다. 봉지에서는 기존대로 개인 회고와 최종 공동 기록을 작성한다. 추모공간을 벗어나도 음량을 자동으로 크게 되돌리지 않는다.

## 6. 에필로그 — 봉지에서 세 기록을 잇다

### B-00. 마지막 집결

**진행 조건:** 네 사람이 봉지 인근의 답사로 지정한 안전한 집결 위치에 도착했다. 수로·계단·차도 가장자리에서 조작하거나 촬영하지 않는다.

**효과:** 세 장의 기록 카드가 천천히 나란히 놓인다. 팡파르나 점수 상승 효과는 사용하지 않는다.

**나레이션:**

> 봉지에 모인 네 사람의 화면에 세 장의 사초가 펼쳐진다. 정문에서 확인한 시작, 용봉관에서 살핀 근거, 추모의 벽에서 읽은 이름들. 이제 무엇을 확인했고 무엇을 배웠는지 서로의 말로 남길 차례다.

| 카드 | 마지막 화면에 표시할 내용 |
| --- | --- |
| 사초① 시작의 기록 | 사건 순서의 검증 결과, 본인의 근거·관찰·사건 기록. 정답 순서 배열은 저장하지 않음 |
| 사초② 검증의 기록 | 본인의 자료·검증 기록과 관람 모드. 통신원의 허용된 자료 기록은 암호해독관에게만 전달 |
| 사초③ 사람의 기록 | 본인의 활동·출처·판단 수정 기록과 팀에 공유하는 공동 문장·근거 |

봉지에서는 새로운 암기 퀴즈나 네 번째 사초를 추가하지 않는다. 여기서 모이는 사초는 총 3개다.

### B-01. 한 사람씩 남기는 마지막 보고

**안내 통신:**

> 마지막 보고는 정답을 맞히는 문제가 아닙니다. 오늘 직접 확인한 것과 판단이 달라진 순간을 한 사람씩 이야기해 주십시오.

| 순서 | 대상 | 화면 질문 | 답안 예시 |
| --- | --- | --- | --- |
| 1 | 정찰원 | 직접 관찰해서 확인한 것은 무엇입니까? | “사진만 봤을 때와 달리 현장에서는 이름과 설명을 함께 확인했습니다.” |
| 2 | 통신원 | 동료에게 정보를 전달할 때 무엇이 중요했습니까? | “단어만 전달하기보다 어디에서 확인했는지 함께 말해야 했습니다.” |
| 3 | 암호해독관 | 처음의 판단을 바꾸게 한 근거는 무엇입니까? | “촬영 정보가 없어 사진의 날짜를 단정할 수 없다는 점을 확인했습니다.” |
| 4 | 지휘관 | 서로 다른 보고를 어떤 기준으로 종합했습니까? | “여러 사람이 같은 답을 말하는지보다 어떤 근거를 확인했는지 살폈습니다.” |

예시는 정답이나 실제 참가자 발언이 아니다. 각자 오늘 경험한 내용을 말하거나 짧게 입력하면 된다. 특정 감정을 표현하도록 요구하지 않는다.

### B-02. 최종 공동 기록

**나레이션:**

> 네 사람의 마지막 보고가 모였다. 처음에는 각자 다른 화면을 보고 있었지만, 지금은 서로가 무엇을 확인했는지 설명할 수 있다. 오늘의 기록을 함께 완성하자.

**화면 문제:**

> 민주주의는 개인의 ______에서 시작해 사람들의 ______로 확산되며, 역사를 정확히 기억하기 위해서는 기록에 대한 ______이 필요하다.

**선택어:** 용기 / 연대 / 책임 / 검증 / 존중 / 참여.

**대표 완성 예시:**

> 민주주의는 개인의 용기에서 시작해 사람들의 연대로 확산되며, 역사를 정확히 기억하기 위해서는 기록에 대한 검증이 필요하다.

이는 성찰 문장으로 하나의 정답을 강제하지 않는다. 다른 조합을 선택했다면 이유를 남긴다. 예를 들어 참여·연대·존중도 팀의 설명과 함께 보관할 수 있다. 선택한 가치에 우열 점수를 부여하지 않는다.

**힌트 대사:**

- 1단계: “세 사초에서 시작, 함께하는 행동, 기록을 읽는 태도를 하나씩 떠올리십시오.”
- 2단계: “첫 칸은 개인의 행동, 둘째 칸은 사람들의 관계, 셋째 칸은 역사를 기억하는 태도를 표현합니다.”
- 3단계: “용기·연대·검증은 한 가지 예시입니다. 팀의 경험을 더 잘 담는 단어가 있다면 그 이유와 함께 선택하십시오.”

**진행 조건:** 네 명은 각자 본인 회고를 저장한다. 회고 본문은 본인에게만 보이며 필요한 내용은 구두로 나눈다. 전원 작성 후 지휘관이 봉지 전용 공동 문장·근거를 저장하고, 각자가 같은 버전에 동의하면 종료된다. 추모의 벽 헌화 상태와는 별도로 봉지 공동 기록을 작성한다. 공동 기록이나 개인 회고 본문을 수정하면 기존 전원 동의를 초기화하고 다시 확인한다. 같은 내용의 재저장은 동의를 초기화하지 않는다.

### B-03. 완료와 결과

**나레이션:**

> 여러분은 장소를 방문하는 데서 끝나지 않고 현장의 글과 사진, 인물의 기록을 비교했습니다. 확인되지 않은 정보를 의심하고 서로 다른 근거를 비교하며 팀원과 함께 판단하는 과정은 오늘날 공동체를 지키는 중요한 역량입니다.

**마지막 안내 통신:**

> 세 장의 사초와 여러분의 공동 기록을 보관했습니다. 오늘의 탐방을 마칩니다.

**결과 화면:**

- 완료한 조사 거점: 3/3. 시작 지점 용봉탑과 마무리 지점 봉지는 별도로 표시한다.
- 수집한 사초: 3/3.
- 기록 수는 자유 기록을 제출한 문제 수로 센다. 교차 확인 수는 선행 문제·보고·자료 연결 조건이 있는 문제를 직접 완료한 건수다. 글의 의미나 사실 이해도를 자동 평가한 점수는 아니다.
- 역할별 완료·보고 현황과 팀 협동 완료 수.
- 사용한 힌트와 해설을 통해 완료한 항목.
- 확인 방식은 실제 저장된 값만 결과에 표시한다. 새 입력에서는 공통 확인 방식을 수집하지 않으므로 비어 있을 수 있고, 현장 확인이나 공식 자료 확인으로 임의 추정하지 않는다.
- 팀이 선택한 가치와 최종 공동 기록.
- 문항 자체의 출처 기록과 과거에 저장한 확인 정보는 각 공개 범위에 맞춰 유지한다. 공통 출처 입력을 추가하거나 자료 조사 성공 여부를 임의로 생성하지 않는다.
- 현재 결과는 완주·사초·역할별 문제와 보고 완료·기록·교차 확인·힌트와 해설 처리·공동 문장을 표시하고 기존 자물쇠 점수를 보조 정보로 제공한다. 시간 점수와 랭킹은 구현하지 않았으며 값은 null이다. 추모·회고에는 점수·감점·숫자 자물쇠를 적용하지 않는다.

## 7. 흐름이 끊겼을 때 사용하는 대사

예외 안내는 역사 속 사건이나 인물의 잘못으로 설명하지 않는다. 참가자의 현재 기기·연결·운영 상태를 간단하게 알리고 이어갈 방법을 제공한다.

### X-01. 잘못된 참가 코드 또는 정원 초과

**잘못된 코드 화면:** “참가 코드를 찾지 못했습니다. 방장 화면의 네 글자를 다시 확인해주세요.”

**정원 초과 화면:** “이 방은 네 명이 모두 참여 중입니다. 방장이 확인한 참가 코드를 입력하거나 다른 방을 만들어주세요.”

### X-02. GPS 거부·정확도 부족·실내 위치 불안정

**나레이션:**

> 위치 신호가 정확하지 않다. 현장 안내와 주변을 먼저 확인하고, 준비된 도착 확인 방법으로 이어가자.

**화면:** GPS 권한 설정과 재측정을 안내하고 전원 도착 조건을 충족할 때까지 미션을 잠근다. 실제 코스에는 QR·수동·진행자 도착 확인 버튼을 제공하지 않는다.

시연 환경에서는 `도착 시뮬레이션`을 제공하고 결과에 시뮬레이션임을 표시한다. GPS 도착 확인은 위치 조건의 충족을 뜻하며 조사 완료나 내용 이해를 판정하지 않는다. 추모의 벽 기준 좌표는 35.178197, 126.907996이며 반경 10m·전원 5초를 적용한다. 개발용 모의 도착은 명시적으로 허용된 모의 검수 코스에서만 네 명이 각각 수행하며 GPS 검수 코스에서는 허용하지 않는다. 실기기 현장 검증은 별도다.

### X-03. 촬영 거부·카메라 사용 불가·촬영 금지

**나레이션:**

> 사진을 남기기 어려운 상황이다. 직접 본 특징과 설명의 위치를 글로 남겨도 조사를 이어갈 수 있다.

**화면:** `관찰 메모 작성` / 허용된 사진이 있는 경우 `사진 업로드` / 시연 환경의 `촬영 시뮬레이션`. 개발 점검에는 승인된 임시 이미지를 사용할 수 있으며 실제 현장 자료가 아님을 표시한다. 실제 사진을 제공받으면 자료 이미지를 교체하며 임시 이미지 승인을 현장 사진 검수 완료로 취급하지 않는다.

촬영 금지 장소에서는 카메라를 열도록 유도하지 않는다. 관찰 메모에는 대상의 이름·확인한 특징·출처를 남긴다.

### X-04. 소리·화면 유지 기능 사용 불가

**화면:** “같은 내용을 자막으로 확인할 수 있습니다.” / “화면 유지가 지원되지 않아도 계속 진행할 수 있습니다. 다시 열면 저장한 역할과 진행 상태로 돌아옵니다.”

음성 청취 여부를 통과 조건으로 삼지 않는다. 추모의 벽에서는 자막을 기본으로 유지한다.

### X-05. 연결 끊김·새로고침·임무 중 이탈

**지휘관 화면:** “○○님의 연결을 확인하고 있습니다. 현장에서 팀원이 함께 있는지 확인해주세요.”

**나레이션:**

> 한 동료의 연결이 잠시 끊겼다. 조사한 내용은 남겨두고, 동료가 돌아오면 같은 지점에서 이어가자.

같은 기기에서는 저장한 참가자·역할·답안·진행 위치를 복원한다. 연결이 돌아올 때 역할을 다시 무작위 배정하지 않는다. 완료하지 않은 역할을 자동 완료로 바꾸지 않는다.

단순한 접속 끊김은 기존 완료를 취소하지 않는다. 새 공동 제출 시에는 현장에서 본인 의사를 다시 확인한다. 기기 고장으로 계속 참여하기 어렵다면 진행자가 해당 참가자의 구두 응답을 대신 기록하고 ‘진행자 대행 입력’으로 남긴다. 네 사람 중 한 명이 실제로 이탈한 경우에는 팀 또는 운영자가 참여 방법을 정한 뒤 진행한다.

### X-06. 제한시간 종료 또는 3단계 힌트

**정문·용봉관 나레이션:**

> 조사 시간을 마무리할 때다. 아직 확인하지 못한 항목은 해설과 근거를 함께 읽고 기록하자. 풀지 못한 문제 때문에 중요한 기록을 놓칠 필요는 없다.

정문·용봉관은 각 역할의 모든 문제가 직접 완료 또는 해설 완료되고 전원 보고를 마친 뒤, 네 명이 각자 공개된 해설을 읽었다고 확인한다. 네 명의 확인이 모이면 지휘관이 별도 해설 개방을 실행한다. 해당 기록은 ‘해설 확인 후 복원’으로 표시하며 독립 해결이나 현장 검증으로 부풀리지 않는다. 이 별도 개방은 추가 자물쇠 시도·감점·무힌트 보너스를 발생시키지 않는다. 새 헌화 코스의 추모의 벽에는 문제·해설 개방 없이 네 사람의 헌화를 적용한다.

추모의 벽에는 실패·시간 종료 연출을 적용하지 않는다. 진행자는 네 사람이 조용히 국화를 올리고 다음 장소로 이동하도록 돕는다.

### X-07. 용봉관 폐관·단체 관람 불가

**진입 나레이션:**

> 오늘은 실내 관람을 진행하기 어렵다. 건물 밖에서 확인할 수 있는 모습과 준비된 공식 디지털 자료로 두 번째 조사를 이어가자.

**대체 방식:**

- 정찰원: 외부에서 건축 특징 관찰, 공식 설명으로 과거 용도 확인.
- 통신원: 준비된 공식 디지털 자료 중 한 점의 유형·기능 조사.
- 암호해독관: 그 자료의 출처·작성 정보·확인 한계 검토.
- 지휘관: 같은 분류·수정 문제와 보고 종합 수행.

공식 디지털 자료의 사용 권한이나 접근이 확보되지 않았다면 해당 실물 자료를 있다고 가정하지 않는다. 유형 학습 카드와 접근 가능한 공식 설명으로 진행하고, 실제 문서 관찰을 하지 않은 항목은 해설 또는 대체 학습으로 표시한다.

공식 운영 정보 연동 전에는 폐관을 자동으로 안다고 가정하지 않는다. 참가자 또는 진행자가 현장에서 확인하여 대체 모드를 선택한다.

### X-08. 안전을 위한 일시 정지

**화면·음성:** “지금은 이동에 집중하세요. 안전한 곳에 멈춘 뒤 조사를 이어갑니다.”

차도·수로·계단 주변에서 촬영, 다이얼 조작, 긴 입력을 요구하지 않는다. 이미 입력한 내용을 보존하고, 안전한 위치에서 재개할 수 있게 한다.
