# 게임 화면 단위 전환

사용자 피드백: 포켓로그처럼 한 화면씩 진행하는 앱/게임 경험. 긴 웹페이지와 사이드바를 제거한다. 기존 PR #3 브랜치에서 수정한다.

게임 캔버스는 화면 높이에 맞추고 전체 페이지를 스크롤하지 않는다. 타이틀→입장→로비→보직→장비→이동→미션→개인 숫자 획득→자물쇠→사초→종료를 한 장면씩 표시한다. 상태 HUD, 장면 일러스트, 하단 선택창의 구조를 모든 화면에서 유지한다. 팀·기록·안내는 메뉴에서 모달로 연다.

미션과 숫자와 자물쇠는 동시에 펼치지 않는다. 지휘관은 자기 숫자 획득 화면에서 자물쇠 화면으로 이동한다. 재접속시 서버 상태로 장면을 복구한다. 서버 정답·역할 권한·점수·대기 규칙은 유지한다. 외부 게임의 코드를 복사하지 않고 자체 SVG 장면과 UI를 만든다.

검증: 한 장면 DOM/페이지 높이, 숫자→자물쇠 분리, 모달 닫기, 모바일/데스크톱 완주·기존 응답 복구, 타입·빌드. 화면 캡처를 교체하고 PR 설명을 최종 구현으로 갱신한다.
