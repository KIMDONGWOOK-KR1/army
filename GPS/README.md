# 호국실록 GPS 실측 도구

- `index.html` : 폰 브라우저로 여는 실측기. 시행별로 GPS 원시 로그(측위값마다 좌표·추정 오차)와 표시선 통과 시각을 기록해 CSV로 저장한다.
- `analyze_gps.py` : 저장한 CSV에 논문 3.2절 판정 규칙(오차 40m 초과 제거, 최근 3개 평균, 반경 안 5초)을 적용해 성공률·오판정·지연을 계산한다.

## 1. 실측기 올리기 (답사 전날까지)

위치 기능은 **https 주소**에서만 동작한다. army 저장소의 GitHub Pages로 배포한다.

- 주소: **https://kimdongwook-kr1.github.io/army/GPS/**
- 설정: army 저장소 Settings › Pages › Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 지정 (최초 1회)
- `main`에 머지된 내용이 1~2분 뒤 반영된다. 이전 `hoguk` 저장소의 실측기 주소는 더 이상 쓰지 않는다.

올린 뒤 **각자 폰에서 한 번 열어** 위치 권한이 뜨는지, "시행 시작"이 되는지 확인한다.
아이폰은 설정 › 개인정보 보호 › 위치 서비스 › Safari 웹사이트 › **정확한 위치 켬**.

## 2. 현장에서

1. 측정자·기기 이름 입력, 거점 선택
2. 기준점 좌표 입력 (위성사진 좌표 권장, 없으면 "지금 위치를 기준점으로")
3. 표시선 거리 입력 (줄자로 기준점에서 30m 지점에 표시)
4. 시행 종류 선택 → 시행 시작 → (진입은 표시선을 지날 때 "표시선 통과") → 시행 종료
5. 거점이 끝날 때마다 **CSV 저장** 후 단톡방/드라이브에 올리기

## 3. 분석

```bash
python3 analyze_gps.py 수집한폴더/*.csv --out 결과
# 반경 후보를 바꾸려면
python3 analyze_gps.py 수집한폴더/*.csv --radii 25,30,35,40 --out 결과
# 동작 확인 (가상 데이터)
python3 analyze_gps.py --demo
```

`결과_summary.md` (논문 표 1에 옮길 요약)와 `결과_trials.csv` (시행별 상세)가 생긴다.
외부 라이브러리 없이 Python 3.8 이상에서 동작한다.
