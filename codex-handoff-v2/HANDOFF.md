# HANDOFF — 호국실록 (2026-10-05 기준)

Codex가 이 저장소에서 바로 이어서 작업할 수 있도록 지금까지의 결정과 남은 일을 정리했다.

## 2026년 10월 6일 일정과 역할 변경

사용자 확정: **10/7 수요일 오후 6시 한국시간 회의 후 분업하여 개발한다. 김동욱은 PM·논문/코드 리뷰어·최종 PR 머지 담당, 이환희는 FE·논문 작성 주담당, 장민호·김종연은 BE·Infra 등 개발 담당이다.** 아래 10/5 기록의 김동욱 개발 담당 및 날짜별 착수 계획보다 이 변경사항을 우선한다. 기존 논문 검토·제출 마감은 유지한다.

공동 개발 저장소는 **[KIMDONGWOOK-KR1/army](https://github.com/KIMDONGWOOK-KR1/army)**다. 담당자와 에이전트가 작업 브랜치에서 PR을 제출하고 김동욱이 읽고 검토·수정 요청한 뒤 직접 머지한다. 논문도 이환희가 작성·수정하고 김동욱이 리뷰한다. 이 문서 갱신만으로 원격 업로드·PR 생성이 완료된 것은 아니다.

회의용 [MVP 개발 기획서](MVP_PLAN.md)와 개정 [PRD](PRD.md)를 작성했다. 장민호 BE·DB / 김종연 Infra·GPS·QA 배정, 4인 MVP와 후순위 기능, 추가 정책은 회의 제안이며 확정 결과가 아니다. 아래 답사·계정 준비는 이전 예정 항목이므로 실제 완료 여부를 확인한다.

## 2. 이미 된 것

- **GPS 실측기** `index.html` — https://kimdongwook-kr1.github.io/hoguk/ (기존 hoguk 저장소의 GitHub Pages, 새 공동 개발 저장소 army와 구분)
  - 시행 종류: 정지 / 진입 / 스치기 / 경계. 측위값마다 좌표·추정 오차를 기록해 CSV로 저장
  - CSV 열: `session,site,device,observer,trial,type,event,t_ms,iso,lat,lng,acc,spd,hdg,ref_lat,ref_lng,line_m,dist` (event: start/fix/mark/end)
  - 판정 미리보기는 논문 3.2절 규칙과 같다(`judgeState`)
- **분석 스크립트** `analyze_gps.py` — 표준 라이브러리만 사용
  ```bash
  python3 analyze_gps.py 수집폴더/*.csv --radii 20,25,30,35,40,45 --out 결과
  ```
  `결과_summary.md`(정지 오차, 반경별 진입 성공률·지연·스치기 오판정·경계 흔들림, 반경 제안, 경고)와 `결과_trials.csv`가 나온다.
- **사전 야간 테스트**(10/5, 아이폰, 정문이 아닌 임의 지점 — 논문 수치로 쓰지 말 것)
  - 1초 간격 기록 정상. 진입 판정 성공, 30m 표시선부터 판정까지 약 6초(머무름 5초 + 평균 지연 약 1초)
  - 정지 24초 중 처음 7초는 4.5m로 안정 → 이후 좌표가 멈추고 추정 오차가 14m→54m로 뛰며 위치가 25m 튐. 40m 필터가 24개 중 17개를 걸러냄 → 3.2절 필터 근거
  - iOS는 추정 오차를 14.2459m처럼 같은 값으로 반복 보고하는 경향
- **1차 시안** `docs/prototype.html` — 폰 4대 화면 흐름 시안(화면·문구 기준)
  - ⚠️ 이 파일은 동욱 PC에 있다. `호국실록 전남대 작전 (Copy).html`을 `docs/prototype.html`로 복사해 커밋할 것
