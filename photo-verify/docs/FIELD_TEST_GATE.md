# 정문 현장 시험 체크리스트

실제 폰으로 정문에서 '사진으로 찾기' 전체 흐름(촬영 → 업로드 → 판정 → 화면)을 확인한다. 기준값·기준 사진은 정답 자료라 이 문서에 적지 않는다(김동욱 보관).

## 준비 (출발 전)
- [ ] 노트북: 판정 서버를 정문 판정 자료로 띄운다 (`docs/fe/SCOUT_SCAN_LOCAL_VERIFY.md` 2단계)
- [ ] 노트북: 웹 개발 서버를 https로 띄운다 (`npm run dev -- --webpack --experimental-https --hostname 0.0.0.0`)
- [ ] 폰과 노트북을 같은 네트워크(노트북 핫스팟 또는 폰 테더링)에 연결하고 `https://<노트북 IP>:3000`이 열리는지 확인
- [ ] 폰 카메라 권한 허용, 자체 서명 인증서 경고는 시험 기기에서만 허용
- [ ] 노트북 전원(판정 1건에 CPU를 많이 쓴다), 기록용 표(아래) 준비
- [ ] 시험에 참여할 폰 기종 2대 이상 (iPhone·Android 섞기)

## 시험 항목
각 항목에서 결과 화면, 셔터부터 결과까지 걸린 시간(초), 실패 횟수 변화를 적는다.

| # | 촬영 | 기대 결과 | 횟수 |
|---|---|---|---|
| 1 | 안내 구도(불꽃문양+아래 명판, 정면 가까이) | 사진으로 찾음 | 5 |
| 2 | 좌우 45도·측면에서 불꽃문양+명판 | 사진으로 찾음 | 5 |
| 3 | 불꽃문양만 가까이 | 사진으로 찾음 | 3 |
| 4 | 조형물 전체(받침·안내판 포함, 몇 걸음 뒤) | 사진으로 찾음 | 3 |
| 5 | 아주 멀리서 조형물이 작게 | 거절될 수 있음 → 안내 문구가 "가까이"로 이끄는지 확인 | 2 |
| 6 | 조형물 아래 안내판만 | 조금 달라요(실패 +1) | 2 |
| 7 | 518 인물 조형물, 광주정신 표지석, 바닥 명판 | 조금 달라요 | 각 1 |
| 8 | 경비실·표지판·하늘·바닥 | 조금 달라요 | 각 1 |
| 9 | 일부러 흔들리게 / 손가락으로 렌즈 일부 가림 | 다시 찍기(실패 횟수 그대로) 또는 판정 | 각 2 |
| 10 | 노트북 판정 서버를 끈 상태에서 촬영 | 연결 오류, 실패 횟수 그대로, 서버 다시 켠 뒤 재시도 성공 | 1 |
| 11 | 실패 3회 채우기 | 3회 뒤 화면 동작(힌트·다음 단계) 확인 | 1 |

## 같이 할 촬영 (평가 자료 보강)
- 쉬운 오답 5장 이상: 하늘, 바닥, 나무, 정문과 무관한 건물 (현재 11장, 목표 15장 이상)
- 다른 조건 회차: 맑은 낮(강한 그림자·역광) 또는 해 질 녘. 정답 30장 이상 + 근처 오답 15장 이상
- 파일은 회차별 폴더로 모아 김동욱에게 전달 (저장소에 올리지 않음)

## 끝나고
- 기록 표와 사진을 `private/photo-verify/`에 정리하고 판정 결과를 평가 보고서에 덧붙인다
- 기대와 다른 항목은 사진과 함께 이슈로 남긴다
